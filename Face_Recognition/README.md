**About:**
</br> This assignment is aimed at understanding advanced methods for face verification and recognition using deep learning. Extracted 128-demensional feature encodings for face images using a pre-trained VGG16 model and a Siamese network architecture, instead of relying on pixel-by-pixel comparisons. Optimizes a triple loss function to enhance the accuracy of face recognition.

**Tools Used:**
* Python Libraries: TensorFlow/Keras, NumPy, Matplotlib, OpenCV.
* Pre-trained Model: VGG16.
* Architecture: Siamese network for encoding face features.
* Platform: Google Colab.

**Learning Outcomes:**
* Learning how to encode face images using a deep learning model.
* Implementing a Siamese network to map face images into useful feature space.
* Optimizing a triple loss function to improve model performance.
