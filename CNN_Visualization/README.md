**About:**
    This assignment is aimed at visualizing and understanding the internal workings of *Convolutional Neural Networks (CNNs)* using the *VGG16* model, which is a pre-trained model. Gained hands-on experience analyzing *feature maps*, *filters* and other key aspects of CNNs; in addition to performing *image pre-processing* and *visualization of intermediate layers*.

**Tools Used:**
    * Python Libraries: Tensorflow/Keras, NumPy, Matplotlib, OpenCV.
    * Pre-trained VGG16 model.
    * Platform: Google Colab.

**Learning Outcomes:**
    * Understanding the architecture and functionality of VGG16.
    * Visualizing intermediate laters, filter maps and filters in CNN.
    * Performing image processing techniques for deep learning.
    * Understanding the application of feature extraction using pre-trained models.
    * Utilizing Python and its libraries for deep leaarning tasks.
