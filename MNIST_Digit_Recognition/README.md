**About:**
</br> This assignment is aimed at building a machine learning model to classify handwritten digits from the MNIST dataset. The dataset consists of greyscale images of digits between 0 and 9. Demonstrated the use of neural networks to acheive high accuracy in digit recognition.

**Tools Used:**
* Python Libraries: TensorFlow/Keras, NumPy, Matplotlib
* MNIST dataset and using CNN architecture

**Learning Outcomes:**
* Understanding the structure and application of CNNs.
* Learning to preprocess data for deep learning models.
* Training model to classify images with high accuracy.
* Analyzing model performance and optimizing hyperparameters for better results.
