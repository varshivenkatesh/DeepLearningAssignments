**About:**
</br> This assignment is aimed at exploring the concept of hybrid images, combining low-frequency components of one image with high-frequency details of another to create a unique visualization. Utilizing image processing techniques such as *Gaussian blurring*, *edge detection* and *frequency domain manipulation.*

**Tools Used:**
* Python Libraries: OpenCV, NumPy, Matplotlib.
* PLatform: Google Colab.

**Learning Outcomes:**
* Understanding the basics of image frequency domains.
* Applying filters to manipulate low and high-frequency components.
* Experimenting with creative visual effects using hybrid images.
* Experience working with Python's image processing libraries.
